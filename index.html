Firebase로 여러 기기에서 같이 쓰기

연결하면 노트와 피드백이 Firestore에 저장돼서 PC·폰 어디서든 같은 내용을 봅니다. 연결하지 않으면 이 브라우저에만 저장됩니다.

  1. Firebase 콘솔에서 프로젝트를 만듭니다.
  2. Authentication에서 익명 또는 이메일/비밀번호 로그인을 켭니다.
  3. Firestore Database를 만듭니다.
  4. 프로젝트 설정 → 내 앱 → 웹 앱 추가 후, firebaseConfig 객체를 그대로 아래에 붙여넣습니다.
Firestore 보안 규칙 예시 
rules_version = '2';
service cloud.firestore {
  match /databases/{db}/documents {
    match /lolNotes/{uid}/{doc=**} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
  }
}
